### Лабораторна робота 5. Robot Repair — вороги і снаряди

Реалізовано ворога, який патрулює за таймером, завдає шкоди при дотику та зупиняється після ремонту; для ворога й робота налаштовано Animator за напрямом руху та окрему анімацію ремонту. Робот стріляє клавішею C, а снаряд не взаємодіє з роботом, ремонтує ворога при влучанні та зникає після зіткнення або віддалення від гравця. Додано паузу між пострілами; швидкість ворога — 1, час розвороту — 3 секунди, Rigidbody2D снаряда кешується в Awake для запуску одразу після Instantiate. C#-скрипти успішно зібрались; перед здачею потрібно перевірити сценарій у Play Mode і записати демонстрацію гри.

### Лабораторна робота 6. Robot Repair — HUD, діалоги та ігровий цикл

Додано HUD зі смугою здоров’я, що оновлюється при отриманні шкоди й лікуванні, діалог NPC з бульбашкою та клавішею X, а також плавні екрани перемоги й поразки з перезапуском рівня через три секунди. Створено NPC із шаром для Raycast, налаштовано UI Toolkit та додано MainScene до списку сцен збірки. Для пошуку HUD використовується єдиний `UIHandler.instance`; `(float)` у формулі здоров’я зберігає дробову частину при діленні. C# збірка пройшла без помилок; у Unity ще потрібно відкрити оновлену сцену й перевірити повний ігровий сценарій у Play Mode.

### 14.11.2026 — Лабораторна 8: механіка-твіст

Додано твіст лабораторної 8: синя колекційка підвищує швидкість робота на 50% протягом 5 секунд, після чого базова швидкість повертається. Параметри Boost Factor і Boost Time доступні в Inspector; DamageZone лишається нерухомою та пульсує як попередження. Таблиця tuning і журнал трьох проходжень є в Documentation/Lab8; фактичні плейтести потрібно записати після запуску в Unity.

### Фінал кампанії

Після ремонту чотирьох ворогів у `MyLevel` з’являється синій анімований портал на основі дев’яти GIF-кадрів. Він переносить того самого персонажа зі збереженим здоров’ям в окрему синьо-темну сцену `BossArena`. Там снарядом треба влучити в боса 15 разів. Лічильник показує прогрес; після останнього влучання гра показує екран перемоги й не перезапускається.
### 15.11.2026 — Лабораторна 9: полішинг і збірка

Що зроблено: додано окремий стартовий екран кампанії, підказки керування, кнопки нової спроби на екранах перемоги й поразки, червоний/зелений спалах персонажа при шкоді й лікуванні. До подій удару, аптечки, пострілу й ремонту ворога під’єднано наявні аудіокліпи. Build Settings містить стартове меню, MyLevel і BossArena саме в такому порядку; вікно налаштовано на 1280×720 у змінному віконному режимі. Додано `Documentation/GDD.md`.

Які знахідки плейтесту виправлено, які ні і чому: під час огляду проєкту знайшов відсутній стартовий екран кампанії, відсутні кнопки повтору та відсутні виклики аудіо для подій. Виправлено в проєкті. Ручний плейтест із трьома проходженнями й тестуванням іншим гравцем ще не виконані.

Що показав запуск `.exe` поза редактором: Windows-білд не створено — Unity у batch mode завершився з кодом 1, бо Licensing Client відхилив з’єднання. Потрібен повторний Build із відкритого Unity Hub/Editor; запуск `.exe` ще не перевірено.

Що не вийшло або забрало найбільше часу: збірка заблокована каналом ліцензування Unity. Компіляція C# окремо через `dotnet build` завершилася успішно (0 помилок, 0 попереджень), але це не замінює перевірку Windows-білда.

Що робитиму до захисту: зібрати Windows-білд у Unity Editor після відновлення каналу ліцензування, запустити `.exe`, пройти від стартового екрана до перемоги, перевірити поразку й перезапуск, отримати плейтест іншого гравця, додати zip до GitHub Release/Drive та внести результати в щоденник.
