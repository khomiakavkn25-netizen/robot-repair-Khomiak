# Щоденник розробника

### Лабораторна робота 5. Robot Repair — вороги і снаряди

Реалізовано ворога, який патрулює за таймером, завдає шкоди при дотику та зупиняється після ремонту. Для ворога й робота налаштовано Animator з рухом за напрямом, а для полагодженого ворога — окремий кліп. Робот запускає снаряд клавішею C; снаряд не взаємодіє з роботом, лагодить ворога при влучанні та видаляється після зіткнення або віддалення від гравця. Додано паузу між пострілами. Для ворога вибрано швидкість 1 і час розвороту 3 секунди; Rigidbody2D снаряда кешується в Awake, щоб його можна було одразу запустити після Instantiate. Скрипти успішно зібралися; перед здачею потрібно перевірити сценарій у Play Mode та записати демонстрацію гри.
