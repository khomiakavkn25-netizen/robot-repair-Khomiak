# Лабораторна 8

Обраний твіст: колекційка швидкості. `SpeedBoostCollectible` задає множник швидкості й тривалість бонусу в Inspector. Після підбору вона зникає, швидкість робота зростає на заданий час, а потім повертається до базової. Нерухомі DamageZone додатково мають пульсуюче попереджувальне світло через `DamageZonePulse`.

`MyLevel` відновлює прямокутну арену з декораціями, NPC та чотирма ремонтованими ворогами з `MainScene`, створює префаб `CollectibleSpeedBoost` і розміщує шість бонусів швидкості на маршруті. Додати їх до наявного `MyLevel` без перебудови карти можна через **Robot Repair → Lab 8 → Add Speed Boosts to Existing MyLevel**. Зони шкоди лишаються нерухомими та пульсують. `MainScene` лишається недоторканою. Меню **Robot Repair → Lab 8 → Build MyLevel with Speed Boost** перебудовує `MyLevel` з `MainScene`, тож збережіть окремі зміни рівня, якщо хочете їх лишити.

Перевірку трьома проходженнями внесіть у `PlaytestLog.md`, а налаштування й діапазони параметрів наведені в `TuningTable.md`. Результати Play Mode потрібно записати після ручного запуску в Unity.
## Кампанія з босом

Після ремонту чотирьох ворогів портал відкриває окрему сцену `BossArena`. Анімований портал використовує дев’ять GIF-кадрів із прозорим фоном. `PortalController` переносить персонажа між сценами зі збереженим здоров’ям; `BossArenaSpawn` розміщує його на вході арени й камера стежить за ним. Арена має синю палітру, бос ремонтується після 15 влучань снарядом.
