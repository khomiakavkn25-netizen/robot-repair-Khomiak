# План рівня MyLevel

Концепція зрізу: «Арена ремонту». Збережено попередній дизайн сцени: довга прямокутна арена з широкою трав’яною галявиною, плитковою рамкою, декораціями навколо, NPC ліворуч і ворогами вздовж маршруту. Аптечки та небезпечні зони задають ритм проходження. У лабораторній 8 одна небезпечна зона стала водою, що підіймається.

## План простору

```text
             декорації / дерева / труби
        ┌───────────────────────────────────┐
        │       плиткова рамка арени        │
        │ NPC   E1   E2    E3   ВИХІД  E4* │
        │ ┌─────── трава / маршрут ───────┐ │
        │ │ аптечка   вода ↑   аптечка    │ │
        │ └───────────────────────────────┘ │
        └───────────────────────────────────┘
             декорації / платформи
```

`NPC` задає мету та підказку; `E1–E3` — звичайні вороги; `E4*` — швидкий варіант; аптечки відновлюють здоров’я; зона шкоди додає небезпеку, але лишає простір для маневру. Після ремонту всіх чотирьох ворогів показується екран перемоги.

Генератор MyLevel бере розкладку і декорації з поточної `MainScene`, тож геометрія залишається такою, як у попередньому дизайні. `MyLevel` є окремою сценою, придатною для налаштувань лабораторної.
